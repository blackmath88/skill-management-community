# AI and capability development

Status: synthesis of the supplied AI report (R3), 11 November 2026. Project functions and study statistics have not been independently rechecked for this intake.

AI has two roles: it changes the work and capabilities organisations may need, and it offers ways to support development.

| Mechanism | Intended contribution | Evidence boundary |
| --- | --- | --- |
| Performance support | Better current output | Does not establish independent learning |
| Tutoring and simulation | More practice, hints and feedback | Feedback validity and real-world transfer need checking |
| Knowledge access | Find relevant sources and cases | Retrieval is not authoritative interpretation |
| Articulating experience | Draft reusable heuristics with experts | Does not fully capture tacit expertise |
| Collective reflection | Surface alternative questions and assumptions | Simulated stakeholders are not participation |
| Skills intelligence | Extract requirements from text | Text claims do not measure a person's competence |

The report's most useful proposal is a human-reviewed loop: relevant situation, targeted support, expert scrutiny, bounded action, review, and selective sharing. It is a design hypothesis, not a validated combined intervention.

For the community: compare concrete cases and challenge interpretations. For the radar: use extraction as an input to relevance discussions, never an automatic target or employee score.
