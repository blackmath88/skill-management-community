# Trend-radar worksheet

Status: ready to try as a draft; untested. Date: 11 November 2026.
Source: [community idea](../../community/sessions/2026-11-11-skills-based-organisation.md), elaborated in the [knowledge note](../../knowledge/topics/future-skills-and-trend-radars.md).

Purpose: translate an external signal into a capability hypothesis relevant to a concrete organisational decision.

| Field | Fill in |
| --- | --- |
| Organisational priority and decision | |
| External signal, source, date and horizon | |
| Confidence and counterevidence | |
| Affected task or work situation | |
| Capability needed under this scenario | |
| Observable behaviour or result | |
| Evidence of current capability, including unknowns | |
| Conditions: time, mandate, resources, access | |
| Target: sustain, develop, source externally or observe | |
| Decision owner and rationale | |
| Small response, review date and revision signal | |

1. Complete one row-set per signal, using synthetic or cleared cases.
2. Have a peer challenge relevance and the proposed capability.
3. Record the decision that changes; park signals that change none.
4. Revisit uncertainty rather than treating the target picture as fixed.

Limits: no employee score; missing documentation does not prove missing capability. Keep actual personnel or sensitive strategy mappings in an approved private location.
